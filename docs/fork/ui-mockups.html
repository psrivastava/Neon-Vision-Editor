How it works: four elevation steps — window/titlebar (darkest) < status bar < tab strip < editor (lightest = focus) — all derived from one theme hue, so flipping the tint re-colors the entire body (chrome included), the KiroCrew behavior. In the app this maps to replacing the fixed grayscale MacEditorSurfacePolicy.windowBackground with surfaces derived from the active editor theme's background hue, stepped by elevation. Accent appears only on active things (tab edge, primary toolbar action, position segment, cursor line).
